# PRD · 《猜猜我》MVP

**项目**：guess-me（独立项目，与本工作区其他内容无关）
**日期**：2026-09-29
**状态**：冻结（MVP）

## 1. 一句话产品

两个人互相出 5 道单选题，通过一条链接完成「互相了解对方」的小游戏，全程无服务器、无账号。

## 2. 目标用户与场景

- 任意两个有手机浏览器的人（A 和 B）。
- A 想测试 B 有多了解自己；B 反向同样出一次题。
- 双方互发链接即可完成，不装 App、不注册。

## 3. 核心流程（固定，不得更改）

A 出 5 道单选题 → A 生成链接 → B 打开并回答 A 的 5 道题 → B 出 5 道单选题 → B 生成返回链接 → A 打开并回答 B 的 5 道题 → 本地计算双方结果 → 显示结果

## 4. 功能需求

| ID | 需求 |
|----|------|
| F1 | A 可创建 5 道单选题，每题 4 个选项、1 个正确答案 |
| F2 | 题目文本 ≤80 字符；选项文本 ≤30 字符 |
| F3 | A 生成分享链接（游戏数据编码进 URL Fragment） |
| F4 | B 打开链接回答 A 的题，答完后 B 创建自己的 5 道题 |
| F5 | B 生成返回链接（含 A 的题 + B 的答案 + B 的题） |
| F6 | A 打开返回链接回答 B 的题，提交后本地计算并显示双方得分 |
| F7 | 分享优先用 navigator.share()，不支持则「复制链接」 |
| F8 | 非法/损坏/缺字段/错版本/题数错/选项数错/答案索引非法/超长 Fragment → 显示「这个链接无效或已经损坏。」，不得抛 JS 错误 |
| F9 | 刷新页面不崩溃（回到当前环节重做即可） |

## 5. 非目标（MVP 明确不做）

自由文本题、多题型、AI、聊天、图片、排行榜、登录、账号、房间、后端、数据库、云存储、情感分析、恋爱评分、动画系统、会员、付费、微信/QQ SDK、Analytics、广告。

以上任何新想法一律进 README 的 Future Ideas，不在 MVP 实现。

## 6. 隐私边界（对外表述钉死）

- 正确表述：**「游戏程序不会把答案上传到服务器。」**
- 禁止表述：「绝对没有网络痕迹」。
- Base64URL 只是编码，不是加密；链接内容对拿到链接的人可读。
- 游戏数据只存在于：URL Fragment（传递中）+ 浏览器内存（运行中）。不使用 Cookie、localStorage 保存答案；不读取联系人/GPS/摄像头/麦克风。

## 7. 成功标准

两个真人用同一份静态页面，走完 §3 全流程并看到正确得分，即为 MVP 成功。
