# 猜猜我（guess-me）· MVP v2

一个无账号、无后端的双人“自答 + 互猜”小游戏。

## 玩法流程

系统从内置精选题库随机抽取 5 道题 → A 先选出自己的真实答案 → 生成链接发给 B → B 猜 A 的 5 个答案 → B 再从题库抽取 5 道不同题并选出自己的答案 → 生成返回链接 → A 猜 B 的答案 → 双方结果在本页本地揭晓。

玩家不再需要自己编写题目。

## 题库

第一版内置 72 道题，分为 8 类，每类 9 题。每局每位玩家从不同类别中随机抽取 5 题；B 会排除 A 已经使用的题目。

题库不预设“正确答案”。“正确答案”就是玩家自己选择的、最符合自己的选项。

题库设计原则：避免模板化情侣问卷、避免纯个人资料题、避免语义重复；四个选项都保持合理性，让“猜”本身有意义。

## 运行

直接打开 `index.html` 可做本地单人流程测试；两部手机实际游玩使用 GitHub Pages：

https://victory-akr.github.io/guess-me/

## 隐私

- 游戏程序不发起网络请求，不使用后端、数据库、账号、广告、统计或第三方 SDK。
- 游戏状态只通过 URL Fragment 和运行时内存传递。
- Fragment 中包含题目和玩家答案；Base64URL 只是编码，不是加密。
- 不使用 Cookie / localStorage / sessionStorage / IndexedDB 保存答案。
- 不读取联系人、GPS、摄像头、麦克风。
- “不上传答案”指游戏程序本身不向服务器提交答案；GitHub Pages 只负责提供静态页面。

## 技术

Vanilla HTML/CSS/JS，无构建、无依赖。

## MVP v2

本版本将旧版“玩家自己出题”改为“精选题库 + 玩家自答 + 对方猜”。不增加 AI API、后端或在线房间。
