# 猜猜我（guess-me）· MVP

两个人互相出 5 道单选题，通过一条链接完成「谁更懂谁」的小游戏。全程无服务器、无账号、无安装。

## 玩法流程

A 出 5 道题 → 生成链接发给 B → B 答题并反过来出 5 道题 → 生成返回链接发给 A → A 答题 → 双方得分在本页本地揭晓。

## 运行方法

直接双击打开 `index.html` 即可（file:// 可用）；或把整个文件夹放到任意静态网页空间。手机玩的话，把页面部署到 http(s) 后双方用手机浏览器打开同一地址。

## 隐私说明

- **游戏程序不会把答案上传到服务器。**（本项目根本没有服务器，也不发起任何网络请求：代码中无 fetch / XMLHttpRequest / WebSocket / 第三方 SDK / Analytics / 广告。）
- 游戏数据只存在于两处：URL Fragment（`#` 后面的编码数据，用于在两人之间传递）和浏览器内存（运行中）。不使用 Cookie / localStorage 保存答案，不读取联系人 / GPS / 摄像头 / 麦克风。
- 注意：Base64URL 只是编码，不是加密——链接里的题目与答案对任何拿到链接的人可读。请只把链接发给你想给对方看的人。本项目不宣称「绝对没有网络痕迹」。

## 规则

- 每人固定 5 道题，单选题；每题 4 个选项，勾选一项为正确答案。
- 题目 ≤80 字符，选项 ≤30 字符。
- 链接无效/损坏/超长/版本不符时，页面显示「这个链接无效或已经损坏。」

## 技术

纯 HTML + CSS + Vanilla JS，三个文件，无构建、无依赖。规格见 `specs/`（PRD / SRS / DESIGN / ACCEPTANCE）。
